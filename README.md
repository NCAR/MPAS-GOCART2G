## Repository layout

- `gocartMPAS/` – core MPAS-GOCART2G code from this repository
- `UPTEMPO/` – emissions processing package 
- `init_MPAS-GOCART2G/` – IC/LBC processing package 
- `docs/` - documentation for the MPAS-GOCART2G Instructions
- `util/` - example build and run script with input configuration files
